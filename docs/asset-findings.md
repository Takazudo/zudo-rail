# 形状・配置の根拠と未確定事項

実測値・出典コミット・SHA256 は [asset-manifest.json](./asset-manifest.json) に記録。製造用 `working/` は変更しない。PCB 原本は `public/assets/panels/` にバイト同一で保存した。外形抽出は `python3 scripts/extract-panels.py`、STL の再監査は `python3 scripts/audit-stl.py` で再現できる（Python 標準ライブラリのみ）。

## 座標と変換

単位は mm（STL 自体に単位情報はない）。世界 X=レール長さ方向、Y=行方向、Z=モジュール前面方向。コア長 L は40HP=204、60HP=305。倍率変更しない。single v3 の Z 範囲は−3.2〜L+3.2だが、端部保持タブを含むためコア長とは区別する。

3U frame は KiCad `(x,y)` を世界 `(Y,Z)=(x,-y)` に、7U frame は `(Y,Z)=(y,-x)` に写す。以下の `u,v` は PCB の対応する穴中心、`s` は手前端−1・反対端+1。最後にモデル全体を中央へ平行移動できる。

| 部品 | 世界X | 世界Y | 世界Z |
| --- | --- | --- | --- |
| NU single | s(z−L/2) | u+s(y−6.7535858154) | −v−(x−14.9305648804) |
| NY single | s(z−L/2) | u+s(x−5.2001) | −v+y−14.42556 |
| double共通 | z−L/2 | x−c+u平均 | −v+y−5.201429 |

double の `c` は2端部軸の平均。NY の軸 X≈5.197922 /17.022431、NU≈6.752716 /18.586121。中心は対向平面から推定したもので、ネイティブ CAD の拘束情報ではない。変換は回転・平行移動のみ。

3U frame の穴中心 `(u,v)` は `(5.997998,15.0303175)` と `(128.533836,15.0303175)`。7U の採用行配列は `u=[6.0332935,128.533836,140.5298535,263.030426,275.0617065,308.7211605]`, `v≈14.9950205`。外側2位置に single、内側の隣接2組に double を置く。double の軸間隔は NY≈11.8245、NU≈11.8334で、PCB の11.9960 /12.0313とは一致しない。中点登録すると片軸約0.08〜0.10mm差が残る。穴の逃げ・ねじ適合・実機組立は未検証であり、この差を隠す変形は行わない。

## バーの座り位置

40HP bar は203.203278×5.503433×4.5、60HPは304.718048×5.502998×4.5。bar 元座標 `(a,b,c)` は長手・幅・厚さの順。長さB、幅Wとすると、NY single の元レール座標への登録は `(x,y,z)=(b+(2.300804+8.131851−W)/2, c+20.716103, a+(L−B)/2)`。これを上記 NY single 変換へ渡す。

double は2溝の X 範囲が `[2.300003,8.134644]` / `[14.092758,19.923889]`。各範囲を `[p,q]` として `(x,y,z)=(b+(p+q−W)/2, c+11.48938, a+(L−B)/2)` を上記 double 変換へ渡す。支持段差を底に採用した寸法上の配置推定であり、摩擦・収縮・加工公差は未検証。

## 端部タブと積層

コア端 X=±L/2から外へ pad1.6mm、その外へframe1.6mm。合計3.2mmはsingleタブの張り出しと一致する。タブは板外形の外側を包む。3U のタブ内側 Y≈−0.1353 /134.6671 に対しframe外形は0〜134.53186、7U は約−0.100 /314.854に対し0〜314.754456。軸方向の重なりだけで干渉と判断せず、コア長をタブ込み全長に置換しない。板自体を2枚ずつ追加して厚くする根拠にはならない。

## ユーザー確認済みの組立・部品単位

7U frame 原本は60.015381×314.754456の**連続した1枚**（外形1本、内部輪郭24本）。左右2枚を取り出す面付けではない。参考caseはこれを左右1枚ずつ使用する。ユーザーの追加回答で参考caseと同じ左右配置を採用することが確定した。プレビューの実数量は**2枚**。以前の原価表の×1を物理数量へ流用せず、2枚を製造する面付けデータとも解釈しない。

ユーザー指定 P75 `zb-side-frame-1u.kicad_pcb` は45.690731×29.990042、穴2個＋長穴2個。case が使用した `1u-padder.kicad_pcb` は45.680609×29.999839、穴2個＋中央開口1個で別形状。ユーザーの追加回答により中央開口付き `1u-padder` を採用した。P75は概算原価用の参照だったため形状に使用しない。比較の根拠として両方の原本を保持する。ユーザー指定材質はアルミPCB。KiCadの1.6mm指定のみでは材質・実製造公差を検証できない。

## STL監査の限界

現行working全STLは座標を1e−6mm精度で比較すると全辺の面共有数2、向き不整合0、重複三角形0。NU double40HPは1686面、60HPは1672面。旧case取り込みSTLの重複面は現行ファイルには見られない。ただし自己交差・強度・実物適合・製造承認を意味しない。

Mac上の修復済みファイルやJLC再アップロード内容とのバイト同一性は未確認。Macアクセスは行っていない。必要なら本manifestのSHA256とユーザー側ファイルを照合する。プレビュー用データを製造保証として扱わない。
