# ナットと表面仕上げの追加対応

## 計画

1. 購入商品画像とユーザー写真を実画像で確認する。
2. 製造STLを変更せず、溝内のナット近似・独立した挿入材色・左右の表面材質を追加する。
3. 全16構成、インスタンス数、間隔、左右表裏、ブラウザ操作を検証し、独立レビュー後に通常PRでmainへ統合する。

## 出典と推定

購入品: [Alibaba M3/M4 Hammer Nut](https://www.alibaba.com/product-detail/M3-M4-Hammer-Nut-Sliding-T_1600233251021.html)。指定仕様はM3炭素鋼・5mmスロット用。
[商品画像](https://s.alicdn.com/@sc04/kf/Hd47923b017664456b1d36852aff671ddR.jpg_200x200.jpg) の実画素を取得して確認。細長い面取り形状と中央ねじ穴は確認できるが寸法図は取得できなかった。標準2020/6mm製品寸法は流用していない。

表示用近似は横10×レール方向4.4×厚さ3.6mm、正面横幅7.2mm、中央穴径3mm。これらは**推定値でありメーカー寸法・製造CADではない**。ねじ山・ローレットは省略。商品写真の見た目と実STL溝断面を根拠にする。

実STL断面: single溝Y=1.199379..12.085548、口幅約4.558mm、X奥行2.987869..7.051666。double溝X=1.201157..12.0856 / 13.255..24.1394、Y=13.0803..17.1441。公称「5mmスロット」と実口幅約4.56mmは同一の検証ではなく適合保証はしない。

single近似の背面X=6.9、正面X=3.3、中心Y=6.642464。double背面Y=13.232、正面Y=16.832、中心X=6.64338/18.6972。長辺は溝を横断、短辺はレール方向、穴軸は前方。各列はHP個を `(i+0.5)*L/HP` に配置（L=204/305）。最短中心間隔5.0833mm、形状幅4.4mmのため隣接ナット間は最低0.6833mm。BOMと表示数は一致（80/120/240/360個）するが固定位置は例示で、実際はモジュールに依存する。

各列1個のInstancedMeshを使用する。選択切替・破棄時に生成geometry/material/instance資源を解放する。黒ナイロンと銀色ナットは樹脂本体の色選択に連動しない。

## 検証

全16構成のBOM・instance数・非重複間隔、黒バー/銀ナットの本体色独立、左右表裏・端面分類、geometry範囲をテスト。ブラウザで全16構成、読込失敗、カメラ、非同期切替・破棄、可視性と分解表示を確認。既存8構成・モバイル・分解の画像を更新し、`screenshots/nuts-exploded.png`を追加する。
